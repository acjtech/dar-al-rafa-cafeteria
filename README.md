# Dar Al Rafa Cafeteria

A static, responsive restaurant website with a menu and WhatsApp ordering page.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `dar-al-rafa-cafeteria`.
2. Upload the contents of this folder to the repository root, including the `.github` folder. Do not upload the parent Websites Collection folder.
3. Push to the `main` branch. The deployment workflow enables GitHub Pages and publishes the website.
4. If GitHub asks you to select a Pages source, choose **GitHub Actions** under **Settings → Pages**.

After the workflow succeeds, the site will be available at:

`https://<your-github-username>.github.io/<repository-name>/`

The order buttons open WhatsApp with a message for the selected dish. The restaurant can confirm current prices and availability there.
