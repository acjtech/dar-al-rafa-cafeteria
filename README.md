# Dar Al Rafa Cafeteria

A static, responsive restaurant website with a menu and WhatsApp ordering page.

## Live website

- Website: <https://acjtech.github.io/dar-al-rafa-cafeteria/>
- Menu & order: <https://acjtech.github.io/dar-al-rafa-cafeteria/order.html>
- Contact: <https://acjtech.github.io/dar-al-rafa-cafeteria/contact.html>
- Source repository: <https://github.com/acjtech/dar-al-rafa-cafeteria>

Updates pushed to `main` are deployed automatically with GitHub Actions. If you recreate this repository, enable **GitHub Actions** under **Settings → Pages**.

The order buttons open WhatsApp with a message for the selected dish. The restaurant can confirm current prices and availability there.
